# Bounded action phase

Implement the action phase of a turn based card game. The phase normally ends when the player's hand reaches `hand_limit`, the policy has no action, or it chooses `END`. Some legal actions draw more cards than they discard; a reshuffle can make such actions repeat forever. `max_actions` is a hard per-phase progress bound. When the bound is reached while the phase is still active, return a forced end instead of calling the policy again. Report the actual hand size and number of actions, and distinguish a normal end from a forced end. Arithmetic must not overflow or underflow. Preserve the API in the visible test.
